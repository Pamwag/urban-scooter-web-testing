# Urban Scooter — Web Application Testing

## 📌 Sobre o projeto

Projeto de **teste manual de uma aplicação web de aluguel de scooters**, realizado como parte da formação em QA.

O objetivo deste projeto é validar o primeiro estágio da tela **"Fazer pedido"**, especificamente o formulário **"Para quem é a scooter" (About Customer)**.

Foram elaborados cenários **positivos e negativos** com base nos requisitos da aplicação. Os testes serão executados em diferentes navegadores e os defeitos encontrados serão registrados no Jira.

## 🎯 Objetivo dos testes

Validar o comportamento e a interface do formulário **"Para quem é a scooter"**, verificando principalmente:

- Preenchimento correto dos campos;
- Validação dos dados inseridos;
- Comportamento para dados inválidos;
- Mensagens de erro;
- Funcionamento dos botões;
- Navegação para a próxima etapa;
- Interface conforme o layout especificado.

## 🧪 Escopo

O escopo deste projeto inclui o primeiro estágio da tela **"Fazer pedido"**:

**Formulário: "Para quem é a scooter"**

### Campos testados

- Nome do cliente;
- Número de telefone.

Foram considerados cenários positivos e negativos para verificar as regras de validação dos campos.

## 🌐 Ambiente de teste

Os testes serão executados nos seguintes ambientes:

| Navegador | Versão | Resolução |
|---|---|---|
| Google Chrome | 85+ | 1280 × 720 |
| Opera | 71+ | 1280 × 720 |

## 🔎 Tipos de teste

- Teste funcional;
- Teste de validação de campos;
- Teste positivo;
- Teste negativo;
- Teste de interface (UI);
- Teste de navegação;
- Teste de compatibilidade entre navegadores.

## 📋 Casos de teste

Os casos de teste foram desenvolvidos com base nos requisitos da aplicação e organizados em uma planilha.

A planilha contém:

- ID do caso de teste;
- Cenário;
- Pré-condições;
- Passos para execução;
- Dados de teste;
- Resultado esperado;
- Resultado obtido;
- Status;
- Link para bugs encontrados.

## 🐞 Registro de bugs

Durante a execução dos testes, os defeitos encontrados serão registrados no **Jira**.

Para cada bug serão documentados, quando aplicável:

- Título;
- Ambiente;
- Passos para reprodução;
- Resultado esperado;
- Resultado atual;
- Severidade;
- Evidências;
- Link para o ticket no Jira.
